# Roblox Script Helper

Lightweight macro / auto-click helper for Roblox on Windows. Great for repetitive mini-game loops where you just want to AFK press a key or click a spot.

## Download

Latest build: **[RobloxMacro.zip](../../releases/latest/download/RobloxMacro.zip)**

Extract the zip and run the installer.

## Requirements

- Windows 10 or 11
- Roblox desktop client
